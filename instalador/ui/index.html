O instalador prepara o AUXILIUM, copia o runtime local e cria os atalhos. O modelo de linguagem entra depois, com uma escolha sua, no primeiro uso.

Instalação isolada

Tudo vai para ~/.local/share/auxilium. Sem sudo e sem mexer no sistema.

Modelo sob controle

Se não houver modelo, o primeiro uso oferece o 1.5B e o 3B com download verificado.

Pronto para usar

Atalho no menu, configuração inicial e acento visual #4f7fae já aplicados.

O download do modelo não faz parte da instalação. O instalador copia apenas o aplicativo. No primeiro uso, se models/ estiver vazio, o AUXILIUM oferece o download do modelo com uma escolha explícita.
Leva menos de um minuto.
